Lead story · Security

nginx2root: the web server behind a huge chunk of the internet had a no-login remote takeover bug

Critical NGINX HTTP/2 bugs allow remote code execution without logging in. Update to 1.30.7 / 1.31.9.

Several research teams independently found memory bugs in NGINX's HTTP/2 code that let a stranger run code on the server. One works on a plain static-file setup. Patched releases came out yesterday.

♥ 2,897⟲ 672🔖 1,966👁 584.9kHN 1,276 ptsWiz ♥ 675
Read the story

NGINX is the web server and reverse proxy that sits in front of a huge share of websites and APIs (probably some of yours). Yesterday several teams, including Wiz Research, Xint, Rapid7, Metnir and Ikotas Labs, disclosed critical memory-safety bugs that can let an attacker run code on the server without logging in. Both of the headline bugs need HTTP/2 to be turned on. Wiz says one of them, CVE-2026-123007, goes back to NGINX 1.9.5 from 2015.

Why the security crowd lost it: Brian Pak's post (2.9k ♥) says “Pre-auth RCE in nginx is the bug every hacker dreams of finding. It almost never happens.” His team's “nginx2root” covers five NGINX bugs and an exploit chain that ends at root, and he says one of them “hits the default config”. Wiz's Nir Ohfeld (1.8k ♥) says they got reliable code execution, with ASLR defeated, on NGINX just serving static files. It was the #1 story on Hacker News with 1,276 points, and the Japanese and Korean security accounts were sounding the alarm overnight.

What to do: nginx.org shipped 1.30.7 (stable) and 1.31.9 (mainline) on Nov 18, fixing these and several other CVEs. Check your version, then upgrade through your distro or nginx.org packages. Docker images need a fresh pull and a redeploy. We're linking the official write-ups and not repeating any exploit details; public PoCs reportedly exist, so don't wait.

Viral weekend project

Someone rebuilt the whole Earth in Minecraft at 1:1 scale, and you can walk to your own house

Earth at 1:1 in Minecraft, generated from map data. Join the server and find your street.

♥ 123.2k⟲ 6,403🔖 121.5k👁 20.4Mposted Nov 16
Read the story

WorldCraft is a Minecraft server that holds a full-scale copy of Earth. Its creator, @cdngdev, explains the recipe in his thread: start with elevation data, add streets and house outlines from open map data (the site credits OpenStreetMap), then let an algorithm add detail from overhead 3D imagery, including furnished interiors.

He says the generator was tuned by a team of more than 250 AI agents working through places around the world, a process he calls “program learning”. Generating the whole planet up front would take about 2 petabytes, so the server builds areas on demand. The US comes first, and the rest of the world is “following soon after”.

It went out on Nov 16 and is still the biggest builder post on X: 123k likes and 121k bookmarks. The server buckled under the load (the site says player counts are limited while they rewrite it). Some players pointed to hand-built projects like EarthMC instead (@Fossilious, 38k ♥).

How to try it: Minecraft Java Edition → Multiplayer → add the server address shown on worldcraft.gg. He also posted a ~6 GB San Francisco world file you can download and open offline.

Open model you can run

An open, Apache-licensed model that strips noise and music out from behind a voice

A free 64M-param model that removes blenders, music and chatter from voices, even live.

♥ 664⟲ 50🔖 690👁 26k@inworld ♥ 421
Read the story

Inworld, a company that makes voice AI, open-sourced its Voice Isolator. You feed it a noisy recording and it gives back only the speaker, keeping how they actually sound. It comes in two versions: a 64M-parameter one for recordings and a 58M-parameter realtime one with 20 ms of look-ahead for live calls and streams. Both output 48 kHz audio.

Hugging Face's Victor Mustar tested it and wrote “this is impressive (can do real time btw) apache 2.0”. His post (664 ♥, 690 🔖) got more likes than Inworld's own announcement. The bookmark count says people plan to try it.

A neat trick from the model card: subtract the isolated voice from the original and you're left with the background. That gives you a rough vocals/music splitter.

TRY ITpip install inworld-voice-isolation

Small model, big claim

Rumble-2-Flash: a 1 GB speech-to-text model built for messy, noisy audio

A 1 GB open speech-to-text model for accents, crosstalk and phone calls, in 40+ languages.

♥ 355⟲ 17🔖 468👁 17.3k@raoulritterr ♥ 283
Read the story

Reson8 released Rumble-2-Flash, open-weights speech recognition aimed at the recordings that usually break transcription: heavy accents, people talking over each other, phone calls and background noise. The weights are about 1 GB and it covers 40+ languages, so it fits on a laptop GPU.

Co-founder @raoulritterr claims it beats models 20× its size and is small enough for a phone. That's their own claim and we haven't checked it. The model card lists an Apache-2.0 license and a Qwen3-ASR architecture, and it runs with Transformers or vLLM.

It pairs nicely with the voice isolator above: clean the audio first, then transcribe it.

Ruby 4.0.10, 3.4.13 and 3.3.14 fix seven bugs, some of which can lead to remote code execution

Seven regex and string bugs in Ruby, some proven to allow remote code execution. Upgrade.

♥ 331⟲ 126🔖 63👁 37.1kHN 185 pts
Read the story

Ruby's maintainers published advisories for seven vulnerabilities in its regular-expression engine and in string case conversion (upcase/downcase). They say they're aware of PoCs showing some can lead to remote code execution, for example in apps that compile regex patterns from user input. CVE numbers are pending, so the advisory uses GitHub (GHSA) IDs.

Aaron Patterson (@tenderlove) posted “Update immediately!” (331 ♥). There's good news for Docker users too: the Ruby core team now co-maintains the official ruby image. @k0kubun says the patched images were up about an hour after release, down from 16 hours last time.

Server tip

Levelsio's NGINX-night tip: turn on automatic security upgrades on your VPS

Levelsio's VPS servers had already patched themselves. Turn on unattended upgrades.

♥ 759⟲ 21🔖 489👁 100.7k
Read the story

When nginx2root dropped, @levelsio checked his VPS servers and found they had “already auto upgraded to the new one”. His advice: enable automatic upgrades now. He even uses automatic reboots, admitting that's “a bit risky if you're not present”. 759 ♥, 489 🔖.

On Ubuntu/Debian that's the unattended-upgrades package, which installs security updates every day. A reboot only happens if you turn on Automatic-Reboot in its config.

TRY ITsudo apt install unattended-upgrades && sudo dpkg-reconfigure -plow unattended-upgrades

ESP32 build

A giant 3D-printed Tamagotchi that's actually a manga reader

A huge Tamagotchi shell around an ESP32-P4 touchscreen that flips manga pages fast.

Hackaday, Nov 18
Read the story

Arnov Sharma 3D-printed a scaled-up Tamagotchi shell around a Waveshare ESP32-P4 Touch LCD 4.3 board (480×800 screen, plus an ESP32-C6 for wireless and a small speaker). Two 2000 mAh Li-ion cells power it.

Recipe: copy manga to an SD card as JPEGs. The P4's hardware JPEG decoder makes page turns quick (software decoding would take 2–5 s), and the firmware boosts contrast on black-and-white scans.
