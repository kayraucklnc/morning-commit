Lead story · Open it now

SolidCraft: a free, open-source Fusion 360-style CAD app in Rust that runs in your browser, and lets your AI agent do the modeling

Parametric CAD with no install and no subscription. Open it and sketch a part.

Sketch, constrain, extrude, fillet, and change one dimension to watch the whole part rebuild. SolidCraft runs as a desktop app, in a browser tab, as a CLI, and as an MCP server so Claude Code or other agents can design parts with you. Wes Bos called it a “clean room” port of Fusion 360 and is already printing gears from it.

♥ 2,195⟲ 76🔖 1,539👁 149.7k★ 18.6kApache-2.0v0.50 · Nov 26

▶ Open SolidCraft in your browser

Read the story

What it is. “An open-source parametric 3D CAD application built in pure Rust.” Parametric means the model is a recipe: a timeline of sketches and features (extrude, revolve, sweep, loft, fillet, shell, holes, threads, patterns) driven by named dimensions. Change one number and everything rebuilds. It has its own constraint solver, assemblies with joints and motion studies, sheet metal, and STEP, 3MF, STL and glTF import/export.

Why it blew up this week. Wes Bos: “I am so dang impressed with how good SolidCraft is. This is the ‘clean room’ port of Fusion 360. It's so fast and the MCP makes agentic design so easy. This is going to completely take over the hobbiest space.” (2.2k likes, 1.5k bookmarks). A day later he posted a 16:1 planetary gearbox launcher toy made in it (590 likes) and the first print-in-place gears off his printer.

The agent angle. The desktop app, browser app, headless CLI and MCP server all run the same commands. Hook it to Claude Code with claude mcp add solidcraft -- solidcraft-cli mcp; with --connect it drives the running app so you can watch the agent model. The README's demo builds a Raspberry Pi 4 case from scratch and then changes its height from 24 to 32 mm in one edit.

Honest status. The README calls it “early but usable for simple parts”: 75 of 76 public reference parts match FreeCAD-computed volume, area and centre of mass. Windows builds are unsigned for now, so SmartScreen may warn. Downloads for Windows, macOS, Linux (AppImage, Snap, Flatpak, .deb, .rpm). Apache-2.0; the repo has 18.6k stars and v0.50 shipped yesterday.

Security · supply chain

PolinRider: malware riding hijacked commits in GitHub repos, where opening the folder in VS Code can be enough

Cloning an unfamiliar repo? Don't trust the workspace until you've looked.

♥ 278⟲ 74🔖 106@TheHackersNews
Read the story

What happened. A campaign linked to North Korea plants a small loader in GitHub repos (in a utils package or conftest.py, or as VS Code auto-run tasks), often by stealing a developer's GitHub token and force-pushing so the final diff looks clean. SafeDep found it in 375 public repos across 260 accounts; The Hacker News' headline put the total above 7,600. The loader reads its server address from an Ethereum transaction, so takedowns don't stop it.

Why it matters. Per the report: “Building the project runs it. In the newest wave, opening the folder in VS Code is enough.” What to do: open untrusted repos in VS Code's Restricted Mode (don't click “Trust”), check .vscode/tasks.json before running anything, and watch for unexpected force-pushes on repos you maintain.

Security · Linux desktop

Flatpak 1.18.6 closes a sandbox escape and a way for a bad app to plant setuid-root files

Using Flatpak apps on Linux? Update Flatpak itself to 1.18.6.

♥ 247⟲ 25@sysxplore
Read the story

What happened. Two holes, per the release notes: a malicious app could “escape the sandbox by manipulating file descriptor passing via flatpak-portal” (CVE-2026-133845), and a malicious app, runtime or extension with extra-data could create “setuid root files on the host system when installed” (CVE-2026-133842).

What to do: update the flatpak package from your distro and check the version. No exploit details here.

Workbench · split-flap display

OpenFlaps: an airport-style split-flap display you 3D-print, one ATtiny85 and stepper per character

Pico W runs the web UI; each flap wheel has 45 printed flaps.

Hackaday · Nov 26
Read the story

Ivan's OpenFlaps is an open-source, 3D-printed split-flap display. A Raspberry Pi Pico W keeps time, coordinates the flaps and serves a Wi-Fi web interface. Each character has its own ATtiny85 board and a cheap 28BYJ-48 stepper driving a wheel of 45 printed flaps. There's room for a BME280 sensor too.

How to build: files and firmware are on GitHub; Hackaday has the overview.
