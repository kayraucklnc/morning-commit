Lead story · Open it now

Karpathy had Claude turn real US data into a Civilization-style map you can browse in your browser. Open it and play

GDP becomes gold, Detroit is “Motor city”. 31 real data sources, one hex map.

Andrej Karpathy asked Claude to populate a Civ-style game map with real public data: Census, BLS, NOAA, USGS, FAA and more, reconciled onto a 25 km hex grid with 19 lenses and a City View for 524 metros. Seven hours and 45K lines of code later, it's live at karpathy.ai/usaciv.

♥ 9,416⟲ 789🔖 5,026👁 522.2kFree, in-browser

▶ Open the USA Civ map

Read the story

What it is. A browsable map of the United States drawn like a Civilization game board, but every tile is real data. Karpathy: “31 real data sources including Census, BEA, BLS, EIA, NOAA, USGS, DoD, NPS, FAA, FEMA, CDC”, covering elevation, land cover, GDP, jobs, power plants, mines, ports, airports, bases, parks, universities, freight flows and disasters, “all reconciled onto one 25 km hex grid.”

The fun part is the translation into game language. Gold yield is GDP. A city's districts are its real industry specializations: “San Jose gets a Campus, Detroit is ‘Motor city’.” Citizens are the real workforce (1 in 4 San Jose workers are engineers, coders or scientists, versus 1 in 14 nationally). Wonders follow published rules: national parks by visitor numbers, universities by R&D spending.

What you can do. Switch between 19 lenses (income, degrees, faith, disasters…), open a City View for 524 metros, consult nine advisors, and use the Explorer to turn any column for any of 3,100+ counties into a table and scatter plot linked to the map. The “?” button links the source. Honest caveat from the man himself: “Claude decided to skip a few states and territories sry.”

How it was made. Claude Code desktop app with Opus 5.5, about 7 hours and 45K lines of code. His post got 9.4k likes and 5k bookmarks overnight. Best on a desktop browser.

Play with it · Postgres in a browser tab

minipg: all of PostgreSQL as one executable, and a demo that runs real Postgres in your browser tab

A .pgdb folder is the whole database. Try the live psql demo first.

HN 53 ptsGitHub ★ 90MIT
Read the story

Jeff Lindsay (progrium) packed PostgreSQL into a single executable. A .pgdb directory is the database: data, config, credentials and Postgres version all live inside it. minipg app.pgdb opens a psql shell; a server starts when needed and stops on its own when idle.

The clever part: it embeds Docker Hub's postgres:18-alpine image and runs Alpine's own Postgres binaries through h9, with a Plan 9 kernel answering their system calls. “There's no Linux kernel to boot, no VM image, and no Docker.”

Try it: the page has a live demo (about 35 MB download; needs Chrome or Edge 137+). Type select 1 and you're talking to real Postgres in a tab. MIT licensed, HN 53 points.

TRY ITminipg app.pgdb "select 1"

Dev tool · pausable JavaScript

Psychoscript: a tiny JavaScript VM that can pause a running script, save it as bytes, and resume it later

Run agent code, freeze it mid-execution, resume it tomorrow. Pure JS, no WASM.

♥ 1,442⟲ 90🔖 708@opencode
Read the story

The opencode team extracted the runtime behind their “code mode” into a standalone package: “it can directly execute js and pause/resume it mid execution.” It's a small bytecode VM for a subset of JavaScript that embeds in Node ≥ 24 or Bun ≥ 1.4, with no WASM, native addon or isolate.

Why people care: an agent's script can wait on a human approval or a slow tool, get saved to bytes, and pick up exactly where it stopped. Scripts only see the host functions you pass in (no fetch, fs or process). The site says 19,408 test262 files pass. A Rust version is in the works. MIT.

TRY ITnpm i psychoscript

Play with it · bare-metal local AI

A 24 KB operating system written in pure assembly that boots straight into a chat with Qwen3-0.6B

No Linux, no C, no libc. Boots in under 100 ms, then you chat.

♥ 8,055⟲ 862🔖 6,939HN 113★ 593
Read the story

@superalesha deleted the operating system from the picture: a 24,252-byte Multiboot kernel in hand-written x86-64 assembly that loads Qwen3-0.6B and drops you at an asm-llm> prompt in 74–94 ms. Multi-turn chat keeps its KV cache, all CPU cores are used.

His claim on X: it runs “up to 54% faster than native Linux llama.cpp.” The README reports 134.9 tokens/s on QEMU KVM with 16 vCPUs and 55.4 tok/s on a diskless Proxmox VM. Needs an x86-64 CPU with AVX2 + FMA + F16C.

Try it: MIT-licensed source, a hybrid BIOS+UEFI ISO builder and Proxmox steps are on GitHub. Build tools: nasm binutils qemu-system-x86. The post hit 8k likes; HN 113.

Open-source tool · Linux audio

Windows' “Loudness Equalization”, reverse-engineered from the DLL and ported to Linux PipeWire

Quiet dialogue, loud explosions? This evens out every app's volume on Linux.

HN 331 pts★ 184
Read the story

One of the Windows features Linux switchers miss most: Loudness Equalization keeps quiet and loud parts at similar levels. This project reverse-engineered it from WMALFXGFXDSP.dll, plus the output limiter from AudioEng.dll so the boost doesn't clip, and rebuilt both as PipeWire modules.

There's an optional GTK window to toggle it globally or per app, and settings are scriptable via pw-metadata (e.g. leave Discord alone). Needs PipeWire ≥ 1.4. HN 331 points.

Security · Linux kernel

NFS2ROOT: a 12-year-old bug let anyone who could reach a Linux NFS server get root, before logging in

Run an NFS server? Update the kernel and reboot. Fixed versions inside.

HN 119 ptsCVSS 9.8
Read the story

What happened. OpenSec found a pre-authentication heap overflow in the Linux kernel's NFS server (nfsd), present since Linux 3.16 (2014). It affects hosts serving NFSv4.1/4.2 (the default) on a reachable TCP port 2049: NAS boxes, file servers, build farms, Kubernetes storage nodes. Rated 9.8 critical (CVE-2026-99362).

The fix. Patched in Linux 6.12.117, 6.18.61, 7.3.2 and 7.4-rc1. Update and reboot; until then, firewall tcp/2049. No exploit details here. HN 119 points.

Related: Hanno Böck noted on oss-security that Ubuntu still hadn't shipped fixes for two severe kernel bugs published 7–9 days earlier (HN 238). Check your distro's tracker.

TRY ITuname -r # compare with 6.12.117 / 6.18.61 / 7.3.2
